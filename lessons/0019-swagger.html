API Documentation: Swagger & OpenAPI

Lesson 0019 · Practical · The developer's handbook

The single idea in this lesson: Manual documentation (like READMEs or Postman collections) dies the moment you change a line of code. Swagger (OpenAPI) automatically reads your NestJS decorators and generates a live, interactive website that is always* in sync with your code.

1. Why Swagger?

When you work in a team, the frontend developer will ask you:
"What is the endpoint for creating a user? What fields does it need? Does it return a 400 or a 404 if it fails?"

Instead of writing a long Slack message, you just send them a link: http://localhost:3000/api. They can see every endpoint, every DTO, and test it themselves without ever seeing your source code.

2. Step 1: Installing Swagger

Run this in your terminal:

npm i @nestjs/swagger

3. Step 2: Initializing the Documentation

You set up Swagger in main.ts. This tells Nest to start a small side-server that hosts the documentation website.

Edit main.ts:


import { NestFactory } from '@nestjs/core';
import { ValidationPipe } from '@nestjs/common';
import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger'; // 1. Import these
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(new ValidationPipe({
    whitelist: true,
    forbidNonWhitelisted: true,
    transform: true,
  }));

  // 2. Configure Swagger
  const config = new DocumentBuilder()
    .setTitle('User Management API')
    .setDescription('The User Management API description')
    .setVersion('1.0')
    .addBearerAuth() // This adds the "Authorize" button for your JWTs!
    .build();
    
  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('api', app, document); // This hosts the docs at /api

  await app.listen(3000);
}
bootstrap();

4. Step 3: Enhancing the Docs with Decorators

Swagger reads your types, but you can make the docs more helpful using special decorators. Edit your DTOs and Controllers.

Edit /src/users/dto/create-user.dto.ts:


import { ApiProperty } from '@nestjs/swagger'; // Import this
import { IsEmail, IsNotEmpty, IsString, MinLength } from 'class-validator';

export class CreateUserDto {
  @ApiProperty({ example: 'sena_dev', description: 'The unique username' })
  @IsString()
  @IsNotEmpty()
  @MinLength(3)
  username: string;

  @ApiProperty({ example: 'sena@example.com' })
  @IsEmail()
  email: string;
}

Edit /src/users/users.controller.ts:


import { ApiTags, ApiOperation, ApiBearerAuth } from '@nestjs/swagger';

@ApiTags('Users') // Groups all these endpoints under "Users" in the UI
@Controller('users')
export class UsersController {
  
  @ApiOperation({ summary: 'Create a new user' })
  @Post()
  async create(@Body() createUserDto: CreateUserDto) {
    return this.usersService.createUser(createUserDto.username, createUserDto.email);
  }

  @ApiBearerAuth() // Tells Swagger this endpoint needs a JWT token
  @Get('me')
  @UseGuards(JwtAuthGuard)
  getMe(@Req() req) {
    return req.user;
  }
}

How to verify your work

  1. Visit the Site: Open http://localhost:3000/api in your browser. You should see the Swagger UI.
  2. Test an Endpoint: Expand the POST /users endpoint, click "Try it out", fill in the example data, and hit "Execute".
  3. Test Authorization:
    1. Click the green "Authorize" button at the top.
    2. Paste your JWT token (the string after "Bearer ").
    3. Try the GET /users/me endpoint. It should now return your user data!
Reflect: You have just automated your documentation. If you add a new field to your DTO or a new endpoint to your controller, the Swagger UI updates instantly when you refresh the page. No more outdated READMEs.
